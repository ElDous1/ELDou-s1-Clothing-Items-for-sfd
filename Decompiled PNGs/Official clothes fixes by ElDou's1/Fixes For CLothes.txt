Format: i usually refer to numbers when a very specific sprite has something wrong, example 1_0 which is part of the idle animation of the torso
  This format comes from the tool from liokindy; "DeluxeBench" im using that format as its the only public tool to extract and import items
  Also used libresprite to draw all that.
  Sometimes i refer "1_x" when i refer to every sprite, as in: every torso sprite.
This is which number is what part:
	0_x is the head
	1_x is the torso
	2_x is the arms
	3_x is the hands
	4_x is the legs
	5_x is the tail; only used on Coat
This text file will go in order according to the layer number.
